# 性斗学园脚本发布规则

每次发布必须使用不可变 Git 标签，不再把 `main` 当作用户更新目标。

1. 将 `scriptUpdater.ts` 中的 `SCRIPT_VERSION` 更新为 `X.Y.Z`。
2. 将 `update-manifest.json` 的 `version` 更新为相同的 `X.Y.Z`，并将 `releaseTag` 更新为 `vX.Y.Z`。
3. 构建并提交对应的 `dist/性斗学园/性斗学园脚本/index.js`。
4. 推送该提交到 `main`，然后在该提交创建并推送不可移动标签 `vX.Y.Z`。
5. 确认 jsDelivr 的 `@vX.Y.Z` 脚本 URL 可访问后，才发布或保留该版本的更新清单。

设置页的“更新至 vX.Y.Z”只会修改当前角色脚本库中、与当前脚本 ID 对应的官方 jsDelivr 导入地址。它会把 `@main`
或旧发布标签替换为 `@vX.Y.Z`，随后刷新页面。即使脚本代码已是最新版本，只要仍使用
`@main`，也会提供固定版本操作。非官方链接、内联脚本、标签不存在或不在角色脚本库中的脚本不会被修改。
